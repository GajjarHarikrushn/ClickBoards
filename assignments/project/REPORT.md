# Project Report - Space Shooter Game on SAM Microcontroller
## 1. Introduction
The purpose of this project was to design a game on SAM Microcontroller using SPI communication with an OLED display and Joystick. The goal was to create interactive game supporting user input, game mechanics (movement, random spawning, shooting, collision detection, background animation), and other tiny features. The project requires control over SPI communication, interrupt, timing, and efficient screen updates to give a seamless experience.
